# RoboLab WebUI 视觉与交互规范

状态：v0.1；用户已确认“简洁、清晰、克制，不要明显 AI 风格”。

## 1. 设计基调

RoboLab 是本地工程工作台，不是营销落地页，也不是聊天产品套壳。界面应让开发者快速判断机器人、Skill、Job 和部署状态。

必须遵守：

- 不使用渐变背景或渐变按钮；
- 不使用霓虹发光、彩色阴影和玻璃拟态；
- 不使用大面积紫色、蓝紫色或“AI 光晕”；
- 不用巨型标题、空洞欢迎语和装饰性动态图；
- 不为了视觉丰富而把简单列表拆成大量卡片；
- 动效只用于状态反馈，持续时间短并支持减少动态效果；
- 危险状态依靠文字、图标和颜色共同表达，不只依靠颜色。

## 2. 色彩基线

首版采用低饱和深色中性界面，具体 token 可在实现时微调：

| Token | 建议值 | 用途 |
|---|---:|---|
| `bg.canvas` | `#111315` | 主背景 |
| `bg.surface` | `#181B1F` | 面板/表格背景 |
| `bg.elevated` | `#20242A` | 菜单、弹层 |
| `border.default` | `#30353C` | 分割线和输入框 |
| `text.primary` | `#E6E8EB` | 主文本 |
| `text.secondary` | `#9DA4AE` | 辅助文本 |
| `accent.primary` | `#5B7FA3` | 选中、链接、主操作 |
| `status.success` | `#5F9273` | 成功/健康 |
| `status.warning` | `#B08A50` | 警告/待确认 |
| `status.danger` | `#B96868` | 错误/停止/危险 |

Accent 只用于关键交互和当前选中状态，不能铺满页面。状态色保持低饱和，但危险动作必须有足够对比度。

## 3. 字体与密度

- 普通界面使用系统 sans-serif，不额外下载品牌字体；
- task id、路径、哈希、命令和日志使用等宽字体；
- 正文以 14px 左右为基线，页面标题保持克制；
- 采用 4/8px spacing scale；表格行高允许 compact/comfortable 切换；
- 长路径、哈希和错误提供复制按钮与完整 tooltip。

## 4. 页面框架

```text
┌──────────────┬──────────────────────────────────────────────┐
│ RoboLab      │ Page title                    Health / Help  │
│              ├──────────────────────────────────────────────┤
│ Dashboard    │ Toolbar / filters / primary action           │
│ Robots       ├──────────────────────────────────────────────┤
│ Skills       │                                              │
│ Jobs         │ Main table, detail panel or split view       │
│ Artifacts    │                                              │
│ Settings     │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

- 固定左侧导航，不使用悬浮胶囊式主导航；
- 页面工具栏只保留当前对象的主要动作；
- 列表到详情优先使用整页或稳定 split view，不叠加多层抽屉；
- Dashboard 展示真实健康度、最近 Job 和失败项，不展示装饰性统计；
- 空状态告诉用户下一步可执行动作，不使用营销插画。

## 5. 组件原则

### 表格与列表

Robot、Skill、Job 和 Artifact 默认使用表格/列表。状态列使用短标签，并显示可读原因。只有需要图像预览或少量对象比较时使用卡片。

### 表单

schema 自动生成的表单按语义分组，始终允许查看 raw YAML/JSON。危险字段显示来源、有效范围和修改影响。

### 日志与事件

日志使用可暂停、搜索、复制的等宽视图；结构化阶段和错误在日志上方单独显示。不要用聊天气泡展示系统日志。

### 确认

- 只读检查和普通仿真不弹确认框；
- Conda 环境、依赖安装和 Profile 修改显示具体变化；
- physical deployment、标定写入和安全配置使用明确对象名与影响范围；
- 禁止只写“Are you sure?”的无上下文对话框。

## 6. Viewer 复用

首版复用 MJLab/Viser/MuJoCo viewer。WebUI 提供：

- viewer session 的启动、停止和健康状态；
- 嵌入可行时使用受控 iframe/页面区域，否则打开本地 viewer URL；
- 当前 Robot/Profile/Job 标识；
- 截图、视频和报告入口；
- viewer 失败时的日志和重启按钮。

不在 MVP 中用 Three.js 重写关节选择、物理仿真或渲染管线。

## 7. Agent UI

未来内置 Agent 也遵循工程工具风格：工具调用、参数、权限和结果是主体，对话文本是辅助。不要使用彩色人格头像、流动光效或全屏聊天作为平台首页。
